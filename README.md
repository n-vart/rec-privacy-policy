# Rec. privacy policy

The public privacy policy for the Rec. iOS photo and video editor.

- Intended website: [n-vart.github.io/rec-privacy-policy](https://n-vart.github.io/rec-privacy-policy/)
- Policy source: [index.html](index.html)
- Effective date: October 19, 2026
- General policy questions: [public GitHub issues](https://github.com/n-vart/rec-privacy-policy/issues)

Do not include media, account or purchase identifiers, or other personal information in public issues.

## Publishing

Publish this repository as `n-vart/rec-privacy-policy`. In the repository’s **Settings → Pages**, select **Deploy from a branch**, then the `main` branch and `/ (root)` folder. Enable HTTPS when available. The page is a standalone HTML file; it needs no build, JavaScript, external fonts, or other assets.

## Maintaining the policy

Update the text and effective date when the app’s data handling changes. The policy distinguishes Rec.’s on-device processing from Apple services, system backups, exports, and GitHub website hosting. It does not promise that device backups or copies shared outside Rec. are deleted when a project is removed.

App Store Connect privacy answers must match the app actually shipped and any included SDKs. Apple’s guidance treats processing that stays on device differently from developer data collection, and distinguishes Apple’s own service data from data collected by the developer. Review purchase data, any support channel, and any future network or analytics changes before submitting privacy disclosures. Publishing this page does not configure App Store Connect.
